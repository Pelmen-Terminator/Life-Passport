# Life Passport / Паспорт жизни V2

**Версия 2.0** — полностью обновленное приложение-чеклист жизненных достижений с расширенными возможностями настройки и персонализации.

## 📱 Демо
Откройте `index.html` в любом современном браузере. Работает на десктопе, планшете и телефоне.

## 🚀 Что нового в V2

### 🎨 Внешний вид
- **Светлая/тёмная тема** — переключение в один клик
- **Адаптивный дизайн** — под телефон, планшет, компьютер, телевизор и автомобиль
- **Обновленная цветовая схема** — комфортная для глаз в любом режиме

### 📱 PWA и офлайн
- **Progressive Web App** — установка на телефон как приложение
- **Офлайн-режим** — работает без интернета (с Service Worker)
- **Индикатор офлайн-статуса** — всегда видно, включен ли режим

### 💾 Управление данными
- **Экспорт в JSON** — полная копия всех данных
- **Экспорт в CSV** — для работы в Excel/Google Sheets
- **Экспорт в PDF** — красивая распечатка достижений
- **Импорт из JSON** — восстановление прогресса с любого устройства

### 📅 Даты выполнения
- У каждой задачи можно указать дату
- Дата сохраняется и отображается
- Редактируется прямо из интерфейса

### 👤 Гендерная настройка
- Выбор «Мужской» или «Женский»
- Автоматически меняет окончания в русских вопросах (получил→получила, купил→купила и т.д.)

### 🔗 Зависимости задач
- Появление подзадач только после выполнения родительской
- Пример: «Купил телефон» → выбор марки (iPhone, Samsung, Huawei, Xiaomi, Realme, Nokia, Redmi)
- Такой же принцип для планшетов, ноутбуков и компьютеров

### 🔄 Скрытие категорий
- Клик по заголовку категории сворачивает/разворачивает ее
- Состояние сохраняется между сессиями

## ⚙️ Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://pelmen-terminator.github.io/Life-Passport/
cd life-passport
```

2. Откройте в браузере:

```bash
open index.html
# или просто дважды кликните по файлу
```

3. Для PWA (опционально):
   Создайте файл sw.js в корневой папке для поддержки офлайн-режима.
