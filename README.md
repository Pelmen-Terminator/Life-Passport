# Life Passport / Паспорт жизни V4
**Версия 4.0** — самое полное обновление приложения-чеклиста жизненных достижений.

## 🚀 Что нового в V4

### 💾 Умное сохранение
- **Автоматическое сохранение:** язык, тема, пол, религия, возраст — всё сохраняется в localStorage
- **Возраст по умолчанию:** при первом запуске автоматически выбирается подходящий возрастной режим
- **Восстановление после перезагрузки:** все настройки и прогресс сохраняются даже после закрытия браузера

### 📚 Расширенные жизненные вехи
- Закончил школу, Закончил колледж, Закончил университет

### 🌍 Больше путешествий
- **Для русских:** Москва, Казань, Санкт-Петербург, Нижний Новгород
- **Для англичан:** Нью-Йорк, Лондон, Вашингтон, Эдинбург

### ⚖️ Новая категория «Право»
- Получал штраф, Сидел в тюрьме

### 🎮 Новые видеоигры
- Tanks Blitz, World of Tanks Blitz, Plague Inc, Zenless Zone Zero, Terraria, Hytale, Shadow Fight 2, Shadow Fight 3, Shadow Fight: Arena

### 🍔 Новая еда
- Ел шаурму, Ел бургер, Ел картошку фри, Ел сладкую вату

### 🌏 16 новых языков
- Турецкий, хинди, нидерландский, казахский, латынь, греческий, украинский, польский, белорусский, шведский, иврит, индонезийский, вьетнамский, корейский

### 🐛 Исправления
- Подзадачи больше не сдвигают остальные вопросы за границу при раскрытии зависимостей
- Улучшена стабильность отображения всех категорий
