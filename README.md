# Life Passport / Паспорт жизни V3
**Версия 3.0** — самое полное обновление приложения-чеклиста жизненных достижений.

## 📱 Демо
Откройте `index.html` в любом современном браузере. Работает на десктопе, планшете и телефоне.

- **Тема:** Светлая / Тёмная
