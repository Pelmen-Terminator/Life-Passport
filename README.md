# Life Passport / Паспорт жизни V1

Бесплатное статическое веб-приложение-чеклист жизненных достижений.  
A free static web-app checklist of life achievements.

## Что нового в V1 / What's new in V1

- **Больше вопросов:** добавлены пункты "Купил Huawei", "Купил Nokia", "Купил Redmi", "Купил Samsung" и другие задачи.
- **Настройка размера экрана:** выберите отображение для телефона, планшета, компьютера, телевизора или автомобиля.
- **Надёжное сохранение:** данные сохраняются в localStorage и не теряются даже после полного удаления и повторного открытия страницы.

## Особенности / Features

- 🇷🇺 / 🇬🇧 Переключение языка на лету — RU / EN language toggle
- 🕊️ Фильтр по религии (христианство, ислам, буддизм, индуизм, иудаизм), скрывающий пункты, связанные с распространёнными пищевыми запретами
- 📊 Прогресс-бар и счётчик выполненных задач
- 💾 Прогресс сохраняется в браузере (localStorage) — сервер не нужен
- 📐 Адаптивный дизайн под разные экраны

## Установка / Installation

1. Склонируйте репозиторий или скачайте файлы.
2. Откройте `index.html` в любом браузере.
3. Готово! Никаких зависимостей или серверов не требуется.

## Использование / Usage

- Отмечайте выполненные задачи кликом по ним.
- Меняйте язык с помощью кнопок RU/EN.
- Используйте фильтр по религии для скрытия пунктов с пищевыми ограничениями.
- Выберите размер экрана для оптимального отображения.
- Прогресс сохраняется автоматически.

## Структура данных / Data Structure

Все задачи хранятся в массиве `TASKS` с полями:
- `id` — уникальный идентификатор
- `cat` — категория (milestones, transport, travel, purchases, languages, food, meat)
- `ru` / `en` — текст на русском и английском
- `tags` — (опционально) теги для религиозных фильтров (pork, beef, horse, shellfish, meat)
- `langOnly` — (опционально) показывать только на указанном языке

## Хранение / Storage

Данные сохраняются в `localStorage` под ключом `life-passport-state-v2`. Это гарантирует сохранность прогресса даже после закрытия или обновления страницы.
