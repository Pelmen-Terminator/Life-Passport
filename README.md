# Life Passport / Паспорт жизни V5
**Версия 5.0** — полное обновление приложения-чеклиста жизненных достижений.

## 🚀 Что нового в V5

### 📦 Раздельный импорт и экспорт
- Импорт: JSON, CSV, PDF (отдельные кнопки)
- Экспорт: JSON, CSV, PDF (отдельные кнопки)
- Удобная группировка в настройках

### 🆕 Новые категории и вопросы

**Новая категория «События»:**
- Олимпийские игры, Евровидение, Интервидение, Чемпионат Мира

**Новые питомцы:**
- Кролик, Енот, Ворона, Рыбки

**Новые блюда:**
- Индейка, Крольчатина, 100-летнее яйцо, Рыба фугу

**Новые жизненные вехи:**
- Отслужил в армии, Побывал на войне
- Исключение из школы, колледжа, университета

**Зависимости для школы:**
- После «Закончил школу»: 9/11 классов (RU) или 9/12 grade (EN)

## 📱 PWA и офлайн-режим

1. При включении офлайн-режима регистрируется Service Worker
2. Все ресурсы кешируются
3. Приложение работает без интернета
